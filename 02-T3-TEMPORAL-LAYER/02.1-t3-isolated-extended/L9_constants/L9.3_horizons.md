## Provenance

### Frame-rate constants
- `FRAME_RATE = 172.27` Hz: **derived** as `44100 / 256` (sample rate divided by hop length, inherited from R³ / Cochlea). Inline derivation in docstring at horizons.py:19.
- `FRAME_DURATION_MS = 5.804`: **derived** as `1000 / FRAME_RATE`. Inline derivation in docstring at horizons.py:22.

### N_HORIZONS = 32
**Specification choice**, partitioned 8+8+8+8 across four perceptual bands (Micro/Meso/Macro/Ultra). Source: `Docs/H3/H3-TEMPORAL-ARCHITECTURE.md` Section 4.

### HORIZON_MS — 32 specific durations
**Source-of-truth document:** `Docs/H3/Registry/HorizonCatalog.md` (authoritative 32-horizon catalog).

Each horizon is annotated inline with its perceptual purpose:

| Band | Horizons | Range |
|---|---|---|
| Micro (H0–H7) | sensory / sub-beat | 5.8 ms – 250 ms |
| Meso (H8–H15) | beat / phrase | 300 ms – 800 ms (slow→fast tempo coverage) |
| Macro (H16–H23) | section / passage | 1 s – 25 s (1 measure→multi-section) |
| Ultra (H24–H31) | movement / full work | 36 s – 981 s (~16 min, full work) |

### HORIZON_FRAMES — derived from HORIZON_MS
**Derivation formula** (inline at horizons.py:74):
```
HORIZON_FRAMES[i] = max(1, round(HORIZON_MS[i] / 1000 * FRAME_RATE))
```

The values in the tuple are the authoritative counts from `HorizonCatalog.md`, which resolve floating-point rounding ambiguities at large horizons. Explicit assertion of the formula belongs in L1 spec_compliance test.

### BAND_RANGES + BAND_ASSIGNMENTS
**Specification choice**: 4 contiguous bands of 8 horizons each (`micro: H0-H7`, `meso: H8-H15`, `macro: H16-H23`, `ultra: H24-H31`).

## Spacing observation (NOT strictly logarithmic)

Inspecting `HORIZON_MS`, the inter-horizon ratio is **not constant** (would be required for strict log-spacing):

| Step | Ratio H_{i+1} / H_i |
|---|---|
| H0→H1 | 2.00 |
| H1→H2 | 1.50 |
| H2→H3 | 1.33 |
| H3→H4 | 1.50 |
| H5→H6 | **4.31** (Micro intra-band jump) |
| H7→H8 | 1.20 (Micro→Meso boundary) |
| H15→H16 | 1.25 (Meso→Macro boundary) |
| H22→H23 | 1.67 |
| H23→H24 | 1.44 (Macro→Ultra boundary) |

The 32 horizons span **5 orders of magnitude** (5.8 ms to 981,000 ms; ratio ≈ 1.69 × 10⁵ over 31 steps). They provide **log-coverage organised in four perceptual bands**, not strict log-spacing.
