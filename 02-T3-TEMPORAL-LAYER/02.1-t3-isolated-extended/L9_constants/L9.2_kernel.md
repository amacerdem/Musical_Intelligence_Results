**Location:** [`Musical_Intelligence/ear/h3/constants/laws.py:42`](../../../../../Musical_Intelligence/ear/h3/constants/laws.py#L42)

## Use

The attention kernel ([`ear/h3/attention/kernel.py:90-95`](../../../../../Musical_Intelligence/ear/h3/attention/kernel.py#L90)) computes:

```python
positions = torch.linspace(0.0, 1.0, window_size, device=device)
weights = torch.exp(-ATTENTION_DECAY * (1.0 - positions))
```

This produces monotonically increasing weights where:
- **Newest frame** (last position, `pos=1`) → weight `exp(0) = 1.0`
- **Oldest frame** (first position, `pos=0`) → weight `exp(-3) ≈ 0.0498`
- **Newest:oldest ratio** = `exp(3) ≈ 20.09`
- **Half-life** = `H · ln(2) / 3 ≈ 0.231 · H`
