### MORPH_MIN_WINDOW — 24 frame-count minima
**Specification + analytical lower bound.** Each value is the smallest window for which the operator is mathematically defined:
- 1 frame: M0/M1/M3/M4 (single-value statistics)
- 2 frames: M2/M5/M8 (need two values for std, range, derivative)
- 3 frames: M6/M9–M11/M16/M18/M19/M21/M22 (need three values for skewness, second derivative, regression)
- 4 frames: M7/M12/M13/M15/M20/M23 (kurtosis needs 4 for excess, etc.)
- 8 frames: M14/M17 (autocorrelation peak detection needs sufficient lags)

Source: `Docs/H3/H3-TEMPORAL-ARCHITECTURE.md` Section 5.1 table.

### SIGNED_MORPHS = {6, 8, 9, 11, 12, 16, 18, 23}
**Specification choice** — the 8 morphs whose raw output spans a signed range centred at zero (skewness, velocity, velocity_mean, acceleration, acceleration_mean, curvature, trend, symmetry). These use the signed normalization formula `output = clamp(raw / scale, -1, 1)`.

Source: `Docs/H3/Morphology/MorphScaling.md` Section 2.2.

### MORPH_SCALE — 24 normalization scales
**Engine-internal scaling parameters**, each annotated inline with its design rationale (`scaling.py:21-46`). Examples:
- `M0/M1/M3/M4 = 1.0`: R³ input already in [0, 1], no rescaling needed.
- `M2 = 0.25`: typical max std on [0, 1] inputs.
- `M8 = 0.1`: typical max velocity ~ 0.1 / frame for [0, 1]-bounded R³.
- `M11 = 0.01`: typical max acceleration ~ 0.01 / frame².
- `M20 = 3.0`: max ≈ log₂(16) = 4.0 bits → 3.0 leaves headroom; entropy cap.
- `M21 = 20.0`, `M22 = 10.0`: typical max counts on bounded windows.

Each scale is **derived from the analytical maximum of its operator on [0, 1]-bounded R³ inputs**, not tuned against human ratings.

Source: `Docs/H3/Morphology/MorphScaling.md` (full table + derivations).
