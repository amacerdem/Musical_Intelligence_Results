# Internal working notes

This subdirectory contains internal working notes from the constant-level
provenance audit (the 9-agent parallel audit completed 2026-05-17). These
documents are bilingual (mixed Turkish / English) and were used by the
authoring team during the audit; they are preserved here for archival and
provenance reasons only.

**The canonical English-language audit outputs are at the parent `_audits/`
level:**

- `audit_combined.csv` — 16,248-row reconciled provenance ledger
- `audit_summary.md` — reviewer-facing summary
- `paper_text_factcheck_2026-05-17.md` — paper-text fact-check
- `escalation_resolutions.md`, `reconciliation_log.md` — process records
- `agent_{1..9}_{audit.csv, summary.md, escalation.md, verification_log.md}` —
  per-agent outputs

External reviewers should read the parent-level files; this folder's
contents are not load-bearing for any paper claim.
